# A real number divided by its absolute value

**Theorem.** For every real number $x$, $x/|x| = 1$ or $x/|x| = -1$.

**Proof.**

**Step 1.** Comparing $x$ with $0$, either $x > 0$ or $x < 0$.

**Step 2.** Case $x > 0$: then $|x| = x$, so $x/|x| = x/x = 1$.

**Step 3.** Case $x < 0$: then $|x| = -x$, so $x/|x| = x/(-x) = -1$.

**Step 4.** Hence $x/|x| = 1$ or $x/|x| = -1$ for every real $x$.

∎
