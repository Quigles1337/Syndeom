# The square root of two is irrational

**Theorem.** For all natural numbers $p$ and $q$ with $\gcd(p, q) = 1$, $p^2 \ne 2q^2$: the square root of two is irrational.

**Proof.**

**Step 1.** Suppose, for contradiction, that $p^2 = 2q^2$ for natural numbers $p$ and $q$ with $\gcd(p, q) = 1$.

**Step 2.** Then $p^2 = 2q^2$ is even, being twice the natural number $q^2$.

**Step 3.** Hence $p$ is even: if $p$ were odd, $p^2$ would be odd, because the square of an odd number is odd. Write $p = 2k$.

**Step 4.** Substituting, $4k^2 = 2q^2$, so $q^2 = 2k^2$ is even, and by the same argument $q$ is even. Write $q = 2m$.

**Step 5.** Thus $2$ divides both $p$ and $q$, so $2$ divides $\gcd(p, q) = 1$, which is absurd. Hence no such $p$ and $q$ exist, and $\sqrt{2}$ is irrational.

∎
