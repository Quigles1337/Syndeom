# An inequality in two real variables

**Theorem.** For all real numbers $x$ and $y$, $0 \le 2x^2 + 2xy + 3y^2 - 2x + 3$.

**Proof.**

**Step 1.** Since squares are non-negative, $(y + 1)^2 \ge 0$, so $0 \le y^2 + 2y + 1$.

**Step 2.** Since squares are non-negative, $(x - 1)^2 \ge 0$, so $y^2 + 2y + 1 \le x^2 + y^2 - 2x + 2y + 2$.

**Step 3.** Since squares are non-negative, $(x + y)^2 \ge 0$, so $x^2 + y^2 - 2x + 2y + 2 \le 2x^2 + 2xy + 2y^2 - 2x + 2y + 2$.

**Step 4.** Since squares are non-negative, $(y - 1)^2 \ge 0$, so $2x^2 + 2xy + 2y^2 - 2x + 2y + 2 \le 2x^2 + 2xy + 3y^2 - 2x + 3$.

∎
