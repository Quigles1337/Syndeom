# Squares of integers modulo four

**Theorem.** For every integer $n$, $n^2 \equiv 0$ or $n^2 \equiv 1 \pmod 4$.

**Proof.**

**Step 1.** Every integer is even or odd: $n = 2k$ or $n = 2k + 1$ for some integer $k$.

**Step 2.** If $n = 2k$, then $n^2 = 4k^2 \equiv 0 \pmod 4$.

**Step 3.** If $n = 2k + 1$, then $n^2 = 4(k^2 + k) + 1 \equiv 1 \pmod 4$.

**Step 4.** In either case, $n^2 \equiv 0$ or $n^2 \equiv 1 \pmod 4$.

∎
