# A zero of the derivative of the absolute value

**Theorem.** Let $f(x) = |x|$. There is $c \in (-1, 1)$ with $f'(c) = 0$.

**Proof.**

**Step 1.** The function $f(x) = |x|$ is continuous on $[-1, 1]$.

**Step 2.** Its values at the endpoints agree: $f(-1) = 1 = f(1)$.

**Step 3.** By Rolle's theorem applied to $f$ on $[-1, 1]$, since $f(-1) = f(1)$, there is $c \in (-1, 1)$ with $f'(c) = 0$.

∎
