## Options considered

the frozen record; Al ruled each one (*Owner decisions recorded*).

- **C1 — `LICENSE` is exact-checked.**
  - (a) `preserve()` skips it, as ADR-0009 D5 skipped the constitution. **Chosen.**
  - (b) Narrow every byte check to the inventory's real inputs.
  - (c) Re-freeze the baseline.
- **C2 — the four crates' `license` fields.**
  - (a)/(i) Change all four. In `preserve()` and in the pair-input check, the exception covers

    and *Consequences*.

  - (c)/(ii) Change only the two crates that are not pair inputs.

- **C3 — `SOURCES.md` is exact-checked,** and the new text needs an S-entry.
  - (a) Make SOURCES.md append-only in `preserve()` and register S-0073. **Chosen.**
  - (b) Record the provenance only in this ADR.
- **C4 — historical "Apache release" statements in frozen files.**
  - (a) Leave them; this ADR supersedes R1. **Chosen.**
  - (b) Append pointers to them, which needs further exceptions.
- **C5 — the S1.2 pair's recorded "SYNDEOM alias wrapper: Apache-2.0".**

    **Chosen.**
  - (b) Re-produce the pair under new identities.

## Decision

- **D1 — The licence.** From the commit that accepts this ADR, SYNDEOM's original software and
  technical documentation are licensed under the **PolyForm Noncommercial License 1.0.0** (SPDX
  `PolyForm-Noncommercial-1.0.0`).
  - Copyright is held personally by **Alexander David Zalewski**.
  - `LICENSE` begins with the line `Required Notice: Copyright 2026 Alexander David Zalewski
    (https://github.com/Quigles1337/Syndeom)` and one blank line, followed by the verbatim
    PolyForm text.
  - Commercial use requires a separate licence from the copyright holder; contact
    **adz@alphx.io**.
- **D2 — What this licence does not cover.**
  - (a) Third-party material keeps its own licence per SD16, as SOURCES.md and each item's
    manifest record it:
    - the redistributable source copies under `sources/`;
    - Mathlib and the Lean toolchain (S-0008, S-0068);
    - the Rust dependencies (S-0008, S-0066; `analysis/s1-3/dependencies.json`);
    - the ground-truth artifacts derived from sources, under `groundtruth/`;
    - any contact corpus under `contact/`.
  - (b) Separately controlled DARQ Labs research materials remain proprietary and outside this
    release; R1(b) is carried forward unchanged.
- **D3 — Earlier grants stand.**
  - Copies obtained under Apache-2.0 before this change remain under Apache-2.0. Every commit
    through `main` `c9372b1355a6d687dec6287f908639ac670db659` was distributed under Apache-2.0,
    and this ADR withdraws none of those grants.
  - The licence an artifact's own manifest records governs that artifact (C5): the S1.2 alias
    wrapper, recorded as Apache-2.0 in `groundtruth/s1_pair_archive-v0.1.0-094625fa10ff/`,
    `groundtruth/s1_pair-v0.1.0-62fe0c816a6b/` and the two proposed configs under
    `analysis/s1-2/`, stays Apache-2.0.
- **D4 — Historical records are not rewritten** (C4). ADR-0000 R1, ADR-0007,
  `analysis/s1-2/README.md`, the advisory note's header, the frozen S1.4 packet, the fixture label
  in `engine/derive/tests/procedure.rs`, S-0019 and HANDOFF's history stay byte-identical. Each
  records what was true when written; this ADR supersedes R1's choice of licence going forward.
- **D5 — Where the licence is stated:**
  - `LICENSE` (D1);
  - README § Licence: a plain-language summary and the contact;
  - the four crates' `license = "PolyForm-Noncommercial-1.0.0"`;
  - S-0073 in SOURCES.md;
  - STATE: the Default-branch bullet, the Q3 bullet (superseded) and the advisory-note bullet;
  - HANDOFF Session 30.
- **D6 — The preservation check: three narrow exceptions.** In
  `engine/ingest/examples/support/effective.rs`:
  1. `preserve()` skips `LICENSE` (C1), which is not an inventory input.
  2. `PROGRAM/SOURCES.md` joins the append-only list (C3). Every existing byte stays checked as a
     prefix.
  3. `LICENSE_LINE_FILES` names the four crate manifests (C2). `license_line_restored()` replaces
     exactly one whole line `license = "PolyForm-Noncommercial-1.0.0"` — line-anchored, a single
     occurrence, nothing else — with the pinned `license = "Apache-2.0"` before comparing. In
     those four files any other difference is still a failure, and in every other file nothing
     is restored. `preserve()` uses it, and so does the reproduction's pair-input check, through
     `pair_input_unchanged()`.

  The output's `preservation` object gains `license_line_only_files_checked`. Nothing else in
  the tool changes.
  - Tool source SHA-256:
    `92a816bcc7cf02acec98bcda1fc7775444f331aede1ca9786c23d750d4dcb30c` →
    `49e6cd6dfa32af4cbfd19cb5433ae2bd7da7471b7a2f8c49d11c2f150d271a67`.
  - The new gate test `engine/ingest/tests/relicense_exceptions.rs` (6 tests) shows each
    exception is narrow:
    - `LICENSE` may hold anything, while a byte added to CLAIMS, ADR-0000, `engine/Cargo.toml`
      or `engine/Cargo.lock` still fails;
    - SOURCES.md accepts an append, but a flipped byte at its start, middle or end, or a
      truncation, still fails;
    - in each crate manifest, the PolyForm line passes and restores to the pinned digest. A
      trailing byte, a changed first byte, a different licence, a trailing space, a duplicated
      line, or a change to the `version` line still fails;
    - the same line in a non-listed file is not restored;
    - the pair-input check allows only the licence line in the two pair manifests and requires
      every other pair input byte-identical.
- **D7 — Numbering and ordering.**
  - The S2 generator decision is ADR-0011.
  - The full narrowing of the byte checks — the standing non-blocking note, now with three
    exceptions beyond ADR-0009's — is the next tool revision. It lands before any S2 code,
    including ADR-0011's crate, because S2's first code commit edits frozen pair inputs
    (`engine/Cargo.toml`, `engine/Cargo.lock`).
