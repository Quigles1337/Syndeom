## Context

SYNDEOM is the third sibling of KOBER and FRIEDMAN. Al designated its home in the genesis prompt:
`https://github.com/Quigles1337/Syndeom`. Discovered this session, from the tools (SD7):

- The remote exists, is **public**, was created 2026-10-12T21:04:39Z, and was **empty** (no
  branches, no default-branch ref, `This repository is empty` from the contents API). GitHub Actions
  is enabled on it (`enabled: true`, `allowed_actions: all`).
- No local clone existed anywhere under `C:\Users\LEET` (case-insensitive `*yndeom*` search, top
  level). The two siblings live at `C:\Users\LEET\KOBER` (`master`, tip `f94bec2`) and
  `C:\Users\LEET\FR13DMAN` (`main`, tip `7c3e5dd`), both clean and in sync with their remotes; the
  machine convention is one repository per directory directly under `C:\Users\LEET`, named exactly
  as the remote, with OneDrive kept repo-free (KOBER ADR-0000 precedent).
- `git clone` of the empty remote reported `HEAD -> refs/heads/main` (the server's unborn HEAD), and
  the REST API reports `default_branch: main`. The machine's own `git init` default is `master`
  (system config `init.defaultBranch = master`), which is why KOBER is on `master` and FRIEDMAN,
  cloned from a GitHub-created repo, is on `main`.
- The machine's system-level git config has `core.autocrlf = true` — the exact trap both siblings
  recorded (CRLF checkouts breaking digests pinned over committed text).
- The siblings' bootstrap commits: KOBER `e3ec346` and FRIEDMAN `eced49d`, both
  `[<X>0][INFRA] bootstrap repo and PROGRAM state architecture`; FRIEDMAN's carried a
  `Co-Authored-By` trailer, KOBER's did not.

Unlike the siblings' Session 1, the constitution was **not** supplied as a file or a verbatim paste.
Al's genesis prompt specified the program (problem, components, phases, invariants, deliverables)
and instructed the executor to author a constitution mirroring the siblings' structure. The draft is
therefore the executor's text, for Al's review.

## Decision

- **D1 — Remote:** `origin` = `https://github.com/Quigles1337/Syndeom` (public; created and
  designated by Al, 2026-10-12). Visibility is Al's owner decision of record; the §4.6 public-facing
  escalation for *publication packaging* remains fully in force at S5.4 regardless.
- **D2 — Local working copy:** `C:\Users\LEET\Syndeom` — option 1, on the KOBER ADR-0000 precedent
  (a bootstrap session is not blocked on a trivially reversible choice). Flagged for confirmation
  as STATE.md Q1.
- **D3 — Default branch:** `main` — discovered from the clone's unborn HEAD and the REST API, not
  chosen and not assumed. The first push establishes it on GitHub. Flagged as Q2 only because the
  siblings differ from each other.
- **D4 — Line endings:** LF pinned repo-wide via `.gitattributes` (`* text=auto eol=lf`, binaries
  excepted), byte-identical to the siblings' file. Verified with `git ls-files --eol` before the
  bootstrap commit.
- **D5 — Commit convention:** §3.9 — `[S<phase>][<CLAIM-ID or ADR-ID or FLAW-ID or INFRA>]
  imperative summary`, authored as `Quigles1337 <adz@alphx.io>`; commit bodies passed via `-F file`.
  Session-1 commits carry the harness-standard `Co-Authored-By: Claude Fable 5.1` trailer
  (FRIEDMAN's bootstrap precedent); whether to keep it is Q16.
- **D6 — Constitution provenance and draft status:** `PROGRAM/SYNDEOM-PROGRAM.md` is
  executor-authored from the genesis prompt of 2026-10-12, mirroring KOBER and FRIEDMAN section for
  section (map in `PROGRAM/SIBLING-MAP-2026-10.md`). It carries a DRAFT marker. Until ratified it
  may be edited freely; the "amended only via ADR" rule binds from ratification onward.
- **D7 — Ratification (pending):** Al reviews the draft and rules on STATE.md Q1–Q17 in Session 2.
  The executor records the rulings as an addendum here, removes the DRAFT marker from the
  constitution header and footer, and records the ratifying commit SHA. Rulings that pin a
  toolchain or a schema become their own ADRs: **ADR-0001 is reserved for the manifest schema
  (S0.4)** and **ADR-0002 for the toolchain pins and scaffold (S0.6)**, mirroring FRIEDMAN's
  numbering. Do not use those numbers for anything else.

## Consequences

- Any digest recorded over a committed text file is stable across clean clones on any platform.
- Public-from-day-0 means SD11/SD16 storage discipline is strict from the start: no stored source
  copy is committed unless its licence permits redistribution.
- No `LICENSE` file exists (neither sibling has one; FRIEDMAN carries it as an open escalation).
  Choosing one is public-facing/legal — Al's (Q3). Until it exists, any crate carries no `license`
  field.
- Nothing in this ADR pins a toolchain; those belong to ADR-0002 after `elan`/`rustc`/`cargo`
  discovery per SD7 (machine inventory as of 2026-10-12 is recorded in SIBLING-MAP §8 for the record,
  not as a pin).
