# ADR-0005 — Constitution amendment, SD15: count-only disclosure of unrelated memory index lines in a cold-start exam

- **Date:** 2026-10-13 (Session 10)
- **Status:** accepted — **Al's ruling of 2026-10-13 (the Session-6 SD15 audit, item (b)),
  approved as a constitution amendment under §3.5 and recorded by the executor in Session 10**
  (ADR-0000 Addendum 3). The convention it makes a rule is the one Session 6 used and flagged.
- **Scope:** the disclosure clause of SD15 — what a cold-start exam session reproduces verbatim in
  its HANDOFF block and what it may withhold. It changes nothing about what memory may hold (D1 of
  FRIEDMAN ADR-0003, adopted), nothing about the conversation-context corollary, and nothing about
  the exam's pass criterion.

## Context

- SD15 as ratified: "In any session attempting a gate's cold-start test, every recalled memory is
  reproduced verbatim as the first entry of the HANDOFF block before any other action; the exam
  counts only if no recalled memory holds program state; no memory writes during an exam session."
- The executor's memory index is one file for every program on the machine. At the Session-6 exam
  it held 99 lines, of which 14 named SYNDEOM or a sibling and 85 concerned unrelated private
  programs. This repository is public (ADR-0000 D1). Reproducing the 85 lines verbatim would have
  published other programs' names, paths and state in a public file for no gain to the exam, whose
  purpose is to show that nothing recalled holds *this* program's state.
- Session 6 resolved the conflict by reproducing verbatim every index line naming SYNDEOM or a
  sibling, and the SYNDEOM memory file in full with its SHA-256, and withholding the 85 unrelated
  lines **by count**, with a recorded check (a case-insensitive search of the index for the
  program's name, matching only the two SYNDEOM lines). It flagged the convention for Al's audit
  and said that, if it should be the rule, it is an SD15 amendment by ADR.
- Al's ruling of 2026-10-13 confirmed the exam's PASS (Gate S0's closure is not provisional; no
  re-run) and ordered the convention made the rule by ADR, with SD15's text amended to cite it.
- Leakage (SD8): nothing here touches contact material or design.

## Options considered

1. **Verbatim everything** (SD15 as ratified) — rejected: publishes unrelated private programs'
   state in a public repository; the exam gains nothing from those lines.
2. **Withhold everything not naming the program** silently — rejected: the exam's disclosure must
   be auditable; a reader must be able to see that nothing relevant was withheld.
3. **Verbatim for every line naming this program or a sibling, plus the program's own memory file
   in full with its digest; count-only for the rest, with a recorded check that none of the
   withheld lines names the program or a sibling** — **chosen** (Session 6's practice).

## Decision

- **D1 — What is reproduced verbatim.** In a cold-start exam session, the first entry of the
  HANDOFF block reproduces, before any other action: (a) every line of the memory index that names
  this program or a sibling program (KOBER, FRIEDMAN), exactly as loaded; (b) this program's own
  memory file in full, exactly as read, with its SHA-256; (c) any other recalled memory the
  harness loaded that names this program.
- **D2 — What may be withheld, and how.** Index lines that concern unrelated programs are withheld
  from the public record **by count**: the entry states how many lines were withheld and which
  line numbers they occupy.
- **D3 — The check.** The entry records a case-insensitive search of the whole index for this
  program's name and its siblings' names, and which line numbers matched; every matched line must
  be among those reproduced under D1 (a). A withheld line that names the program is a disclosure
  failure, and the exam does not count.
- **D4 — The pass criterion is unchanged.** The exam counts only if no reproduced memory holds
  program state (SD15's enumeration); withheld lines are outside the program by D3 and cannot
  hold its state. No memory is written during an exam session.
- **D5 — Retroactivity.** Session 6's disclosure already followed D1–D3; its PASS stands as
  confirmed by Al, and this ADR records the rule it used.

## Consequences

- SD15's disclosure sentence is replaced in the same commit by text matching D1–D4, citing this
  ADR; the constitution's header and footer *Amendments* lines gain ADR-0005.
- STATE's memory-policy paragraph cites this ADR; the Session-6 audit escalation closes as
  confirmed; Gate S0's closure is recorded as not provisional.
- Housekeeping ordered with the same ruling (item (a)), done in Session 10 (not an exam session):
  the executor's SYNDEOM memory file loses the paragraph that paraphrased constitution rules

  and the repo location — and keeps the `fmt --check` hazard line, which is a hazard. The file's
  new SHA-256 is recorded in HANDOFF Session 10 beside the Session-6 digest.
- The siblings' constitutions are not touched (a sibling ADR is a sibling session); SIBLING-MAP's
  statement that the three loops are identical acquires one more load-bearing difference, recorded
  there only when that file is next revised.

~~~text

Both memory digests you computed already appear in HANDOFF, in disclosures that reproduced these exact bytes. **Effect on D1–D4.**
~~~
- **D1** applies verbatim reproduction only to a memory file whose SHA-256 is new. When every
  file's digest matches an earlier HANDOFF disclosure that reproduced the same bytes, the
  disclosure records instead:
  - each file's SHA-256, line count and byte facts;
  - the matched index line numbers and the withheld count;
  - a citation of that earlier entry.
- **D2 and D3 are unchanged.** The withheld count, the line numbers and the recorded name search
  are still made and recorded.
- **D4 is unchanged.**
- If a digest is new and its verbatim reproduction cannot be completed, the session stops and
  escalates to Al. It does not work around the failure.

**First application.** HANDOFF Session 37, Entries 1 and 2:

- Entry 2 is the citation, located after the append so that the disclosure stays first. It cites
  Session 35's Entry 1 and was verified by hashing the reproduced bytes, not only by matching the
  stated digests.

**What this amendment does not touch.**
- SD15's sentence in the constitution still says the program's memory file "is reproduced
  verbatim". This amendment does not edit the constitution's bytes, its *Amendments* lines or
  ADR-0009.
- Whether SD15's text should be amended to cite this ruling is a constitution amendment (§3.5,
